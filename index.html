1. Komitmen Privasi Kami

Selamat datang di game Tembak 2048! Game ini dikembangkan dan dikelola oleh Rona Pratama Citra Abadi. Kami menghargai dan menjamin privasi Anda sepenuhnya saat memainkan game ini.

⚠️ PENEGASAN PENTING: Game ini ditujukan khusus untuk pengguna berusia 13 tahun ke atas. Kami TIDAK PERNAH MENYIMPAN dan TIDAK PERNAH MEMBAGIKAN data pribadi pengguna apa pun kepada pihak luar atau pihak ketiga mana pun.

Kebijakan Privasi ini menjelaskan prinsip perlindungan data saat Anda mengunduh, memasang, dan memainkan Tembak 2048 di perangkat Android Anda.

🛡️

2. Kami Tidak Menyimpan & Tidak Membagikan Data Anda

Kebijakan kami sangat tegas: Kami TIDAK mengumpulkan, TIDAK menyimpan di server eksternal, dan TIDAK membagikan informasi pribadi atau data pengguna apa pun.

  • 🚫 Tidak Ada Penyimpanan Server: Kami tidak memiliki server eksternal untuk melacak identitas, nama, email, nomor HP, kontak, maupun lokasi geografis Anda.
  • 🚫 Tidak Ada Penjualan/Pembagian Data: Data Anda tidak pernah dan tidak akan pernah dijual, disewakan, atau dibagikan kepada pihak ketiga atau pengiklan mana pun.
  • 💾 Data Offline Lokal Saja: Capaian skor balok 2048 dan preferensi audio hanya tersimpan secara offline di penyimpanan lokal memori HP Anda sendiri.
  • 🚫 Tanpa Registrasi / Akun: Anda dapat langsung memainkan game tanpa memerlukan akun, kata sandi, ataupun login media sosial.
🔞

3. Batasan Usia: Khusus Pengguna 13 Tahun ke Atas

Game Tembak 2048 dirancang dan ditujukan secara eksklusif bagi pemain yang berusia 13 tahun ke atas (Teen 13+). Game ini tidak ditujukan untuk anak-anak di bawah umur 13 tahun.

Karena sistem kami berprinsip Zero Data Collection, kami tidak mengumpulkan informasi pengenal pribadi apa pun dari siapa pun, termasuk tidak mengumpulkan data apa pun dari anak-anak di bawah umur.

📱

4. Izin Akses Perangkat (Permissions)

Aplikasi Tembak 2048 hanya menggunakan izin internal standar Android untuk pengalaman bermain di perangkat lokal Anda:

  • 🔔 Notifikasi (POST_NOTIFICATIONS): Hanya untuk pemberitahuan lokal pengingat santai bermain di HP Anda sendiri (tanpa mengirim data keluar).
  • ⏰ Penjadwalan Alarm (SCHEDULE_EXACT_ALARM): Digunakan untuk pengingat waktu lokal di sistem HP Anda.
  • 🌐 Konektivitas Dasar (INTERNET & ACCESS_NETWORK_STATE): Diperlukan untuk komunikasi modul engine Unity standar.

Anda dapat menonaktifkan izin notifikasi kapan saja melalui menu Pengaturan Aplikasi di ponsel Anda tanpa mengganggu jalannya permainan game.

🧩

5. Framework Engine Game (Unity Technologies)

Aplikasi ini dibangun menggunakan framework Unity Technologies. Unity hanya membaca parameter teknis perangkat dasar (seperti resolusi layar grafis dan tipe GPU) untuk keperluan rendering balok 3D secara lancar pada perangkat Anda. Tidak ada data pribadi pengguna yang disimpan atau dieksploitasi.

Kebijakan penanganan data engine Unity dapat dilihat pada tautan resmi: Unity Privacy Policy.

🔐

6. Kendali Penuh & Penghapusan Data

Karena semua skor hanya tersimpan di memori lokal HP Anda, Anda memegang kendali 100%. Untuk menghapus semua skor dan preferensi game, Anda cukup memilih menu Hapus Data / Clear Storage pada menu Pengaturan Aplikasi ponsel, atau menghapus pemasangan (uninstall) aplikasi dari perangkat Anda.

🔄

7. Perubahan Kebijakan Privasi

Apabila terdapat pembaruan teknis di masa mendatang, dokumen ini akan diperbarui secara langsung pada halaman resmi ini. Kami tetap berpegang teguh pada komitmen bahwa kami tidak akan pernah menyimpan atau membagikan data pribadi pemain kami.
