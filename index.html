1. Komitmen Privasi Kami

Selamat datang di game Tembak 2048! Game ini dikembangkan dan dikelola oleh Rona Pratama Citra Abadi. Kami sangat menghargai privasi para pemain kami dan berkomitmen penuh untuk melindungi informasi Anda selama memainkan game santai ini.

Kebijakan Privasi ini menjelaskan jenis data apa yang diproses (atau tidak diproses) saat Anda mengunduh, memasang, dan memainkan Tembak 2048 di perangkat Android Anda.

🎯

2. Pengumpulan dan Penggunaan Data

Kami TIDAK mengumpulkan informasi pribadi yang dapat mengidentifikasi Anda (seperti nama asli, nomor telepon, alamat rumah, informasi rekening bank, maupun data lokasi GPS).

  • ✅ Skor dan Level: Disimpan secara lokal di memori perangkat Anda (Local Storage) untuk menyimpan capaian rekor balok 2048.
  • ✅ Preferensi Pengguna: Pilihan suara/efek audio dan preferensi bahasa (Inggris/Indonesia) disimpan langsung di HP Anda.
  • 🚫 Tidak Ada Pendaftaran: Anda dapat langsung memainkan game tanpa harus membuat akun atau login.
📱

3. Izin Akses Perangkat (Permissions)

Aplikasi Tembak 2048 hanya memerlukan izin dasar standar Android untuk pengoperasian game yang lancar:

  • 🔔 Notifikasi (POST_NOTIFICATIONS): Digunakan untuk memberikan pengingat bermain atau informasi hadiah harian santai secara lokal.
  • ⏰ Alarm / Pengingat (SCHEDULE_EXACT_ALARM): Digunakan oleh sistem penjadwalan lokal game untuk fitur pengingat di perangkat Anda.
  • 🌐 Konektivitas Jaringan Dasar (INTERNET & ACCESS_NETWORK_STATE): Digunakan untuk koneksi dasar engine game.

Anda dapat menonaktifkan izin notifikasi kapan saja melalui menu Pengaturan Aplikasi di ponsel Anda tanpa mengurangi keseruan bermain game.

🧩

4. Layanan Pihak Ketiga & Engine

Game ini dibangun menggunakan framework Unity Technologies. Unity dapat memproses data teknis non-pribadi perangkat standar (seperti model ponsel, versi OS, resolusi layar) semata-mata untuk tujuan optimalisasi grafis 3D dan stabilitas performa game.

Untuk mempelajari kebijakan penanganan data Unity, Anda dapat mengunjungi Kebijakan Privasi Unity.

🧸

5. Perlindungan Privasi Anak (COPPA)

Game Tembak 2048 ramah untuk semua usia, termasuk keluarga dan anak-anak. Kami tidak pernah secara sadar mengumpulkan data pengenal pribadi apa pun dari anak-anak di bawah umur (di bawah 13 tahun) sesuai dengan undang-undang Children's Online Privacy Protection Act (COPPA).

🔐

6. Keamanan Data & Hak Anda

Karena semua data skor disimpan secara lokal di ponsel Anda, Anda memiliki kendali penuh 100%. Jika Anda ingin menghapus seluruh data skor dan riwayat permainan, Anda cukup melakukan Clear Data (Hapus Data) pada menu info aplikasi Tembak 2048 di pengaturan HP, atau menghapus instalasi (uninstall) game.

🔄

7. Perubahan Kebijakan Privasi

Kami dapat memperbarui dokumen Kebijakan Privasi ini dari waktu ke waktu jika terdapat pembaruan fitur pada aplikasi. Segala perubahan akan langsung diperbarui pada halaman ini beserta tanggal revisi terbaru.
